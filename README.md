# Push-Swap

Две маленькие программы на Go: одна **придумывает** команды для сортировки чисел, вторая **проверяет**, что команды действительно работают.

---

## О чём проект — совсем простыми словами

Представьте **две стопки чисел** (стеки):

- **Стек A** — сюда вы кладёте числа из аргументов. **Самое первое число в строке лежит сверху.**
- **Стек B** — пустой, вспомогательный.

Можно делать только **12 видов действий**: перекладывать верхнее число между стеками, менять два верхних местами, «крутить» стек (верхний уходит вниз или наоборот). Подробная таблица — ниже.

**Задача:** в стеке A числа должны идти **по возрастанию сверху вниз** (самое маленькое — наверху), стек B — пустой. Нужно сделать это **как можно меньшим числом команд**.

**push-swap** — печатает эти команды (по одной на строку).  
**checker** — читает те же числа и команды и пишет `OK`, если всё сошлось, иначе `KO`.

Если передали «битые» данные (не число, повтор) — в stderr одно слово: `Error`.

---

## Две программы

| Программа   | Что делает |
|------------|------------|
| **push-swap** | Числа → минимальный набор команд для сортировки |
| **checker**   | Числа + команды → `OK` или `KO` |

Связка из задания (должна печатать `OK`):

```bash
ARG="4 67 3 87 23"; ./push-swap "$ARG" | ./checker "$ARG"
```

---

## Команды (шпаргалка)

| Команда | Смысл |
|---------|--------|
| `pa` / `pb` | Взять верхнее из B → в A / из A → в B |
| `sa` / `sb` | Поменять два верхних в A / в B |
| `ss` | `sa` и `sb` сразу |
| `ra` / `rb` | «Прокрутить» стек вверх (верхний вниз) |
| `rr` | `ra` и `rb` сразу |
| `rra` / `rrb` | Прокрутка в обратную сторону |
| `rrr` | `rra` и `rrb` сразу |

**Пример:** вход `2 1 3` — сверху в A лежит `2`, потом `1`, потом `3`. Нужно получить сверху вниз: `1`, `2`, `3`.

## Сборка

### Windows

```powershell
.\build.ps1
```

Появятся файлы `checker.exe` и `push-swap.exe`.

Или вручную:

```powershell
go build -o checker.exe ./cmd/checker
go build -o push-swap.exe ./cmd/push-swap
```

### Linux / macOS

```bash
make all
```

Или:

```bash
go build -o checker ./cmd/checker
go build -o push-swap ./cmd/push-swap
```

> Исполняемые файлы в корне в git не кладут. Исходники — в `cmd/`.

## Использование

### push-swap

```powershell
# Windows
.\push-swap.exe "2 1 3 6 5 8"
```

```bash
# Linux / macOS
./push-swap "2 1 3 6 5 8"
```

| Ситуация | Результат |
|----------|-----------|
| Без аргументов | Ничего не выводит |
| Уже отсортировано (`0 1 2 3`) | Ничего не выводит |
| Не число (`0 one 2`) | `Error` в stderr |
| Дубликаты (`1 2 2 3`) | `Error` в stderr |

Числа можно передать одной строкой `"2 1 3"` или отдельными аргументами `2 1 3`.

### checker

Команды подаются **по одной на строку** (через pipe или ввод с клавиатуры).

```powershell
# Windows — проверка готовых команд
"pb`npb`nra`nsa`nrrr`npa`npa" | .\checker.exe "2 1 3 6 5 8"
# OK

# Автопроверка: push-swap | checker
$ARG = "4 67 3 87 23"
.\push-swap.exe $ARG | .\checker.exe $ARG
# OK
```

```bash
# Linux / macOS
echo -e "pb\npb\nra\nsa\nrrr\npa\npa" | ./checker "2 1 3 6 5 8"
ARG="4 67 3 87 23"; ./push-swap "$ARG" | ./checker "$ARG"
```

**Подсказка:** если запустить checker без pipe, он ждёт ввод. Пустая строка + Enter (на Windows ещё можно Ctrl+Z, Enter) — закончит ввод; если стек не отсортирован, будет `KO`.

## Проверка как на задании (PowerShell)

В условии команды для bash. В PowerShell так:

```powershell
.\build.ps1

.\push-swap.exe                          # пусто
.\push-swap.exe "2 1 3 6 5 8"            # < 9 команд, checker → OK
.\push-swap.exe "0 1 2 3 4 5"            # пусто
.\push-swap.exe "0 one 2 3"              # Error
.\push-swap.exe "1 2 2 3"                # Error

"sa`npb`nrrr" | .\checker.exe "0 9 1 8 2 7 3 6 4 5"   # KO
"pb`nra`npb`nra`nsa`nra`npa`npa" | .\checker.exe "0 9 1 8 2"   # OK

$ARG = "4 67 3 87 23"
.\push-swap.exe $ARG | .\checker.exe $ARG   # OK

# 100 случайных чисел: < 700 команд и OK
$nums = (0..9999 | Get-Random -Count 100) -join ' '
$out = .\push-swap.exe $nums
($out | Measure-Object -Line).Lines
$out | .\checker.exe $nums
```

**Частые ошибки в PowerShell:**

- `build.ps1` → нужно `.\build.ps1`
- `echo -e` в bash здесь не работает → строка с `` `n ``
- `ARG="..."` → `$ARG = "..."`

## Как устроена сортировка (для любопытных)

1. **2–3 числа** — заранее подобранные короткие цепочки команд.
2. **4–6 чисел** — минимальные уезжают в B, остаток сортируется, потом возврат в A.
3. **7 и больше** — ищется длинная возрастающая подпоследовательность (LIS): часть чисел остаётся в A, остальное через B возвращается с учётом дешёвых поворотов (`rr`, `rrr`).

Используются **только стандартные пакеты Go**.
